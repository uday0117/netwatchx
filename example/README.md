# NetWatchX Example

This example demonstrates how to use the `netwatchx` package to monitor internet connectivity in a Flutter application.

## Features Demonstrated

- Real-time internet connectivity monitoring
- Initial connection check on app startup
- UI updates based on network status changes

## Running the Example

1. Ensure you have Flutter installed and set up
2. Navigate to the example directory:
   ```bash
   cd example
   ```
3. Get dependencies:
   ```bash
   flutter pub get
   ```
4. Run the app:
   ```bash
   flutter run
   ```

## Testing

To test the connectivity monitoring:
1. Run the app on a device or emulator
2. Toggle airplane mode or Wi-Fi on/off
3. Watch the app automatically detect and display the connection status changes
